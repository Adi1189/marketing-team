# Marketing Team · Dr. Ardeleanu

Site static (HTML/CSS/JS, fără build).

## Rulare locală
Deschide `index.html` în browser (dublu-click).
Sau, din folderul proiectului: `python -m http.server 8000` și apoi http://localhost:8000

## Structură
```
index.html
css/style.css
js/main.js
assets/logo.png
```
